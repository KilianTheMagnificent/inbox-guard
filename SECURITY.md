# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a bypass in attachment magic-byte screening, CSV formula neutralization, hidden-Unicode detection, or PII tokenization, please report it privately via GitHub's [Private Vulnerability Reporting](https://github.com/KilianTheMagnificent/inbox-guard/security/advisories/new) rather than opening a public issue.

Reports are triaged within 72 hours, and regression tests are added for every confirmed bypass before a patch release is published.
