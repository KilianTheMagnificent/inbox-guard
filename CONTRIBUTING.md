# Helping with inbox-guard

If a command gives a surprising result or an instruction is hard to follow, open an issue. Include your Node.js version (`node --version`), the command you ran, a short invented input, and the expected and actual output. Use a made-up address such as `orders@example.org` and keep real messages, attachments and contact details private.

Andre directs development with AI assistance and currently accepts feedback through issues. Outside code contributions are closed because Andre cannot personally review them.

For a suspected vulnerability, use the private reporting instructions in [SECURITY.md](SECURITY.md).
